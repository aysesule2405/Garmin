Please note, if you would like to display a pixel logo at a size not already provided here, 
please use the following method:

1. Open the smallest logo (labelled 1x) in an image editor
2. Using the "nearest neighbor" scaling algorithm, resize the image only by doubling, tripling, etc... 
so for example, resize by 100%, 200%, 600%, 900%, etc... but not at 350%, 720% or 278%. 
Using non-whole-integer values for resizing will result in a distorted image. Using anything but "nearest neighbor" scaling
will result in blurry pixels. The logo must be displayed with crisp, undistorted pixels.

For the vector logo (CA_logo_vector_4x.png), it's fine to scale it to any size, as long as it doesn't start to look grainy.
For resizing the vector logo, don't use nearest neighbor, but instead bilinear, bicubic, or something else that preserves the smoothness.
